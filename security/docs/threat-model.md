# Mini threat model — index72

## Scope

Публичный учебный кейс `Интер РАО · Система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Контейнеры / hardening / health / мониторинг

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Запуск от root | Контейнер имеет лишние права | Non-root USER |
| T2 | Запись во всю FS | Компрометация меняет приложение | read_only + tmpfs для временных данных |
| T3 | Нет healthcheck | Сервис завис, но считается живым | /health + healthcheck |
| T4 | Нет ограничений | Процесс потребляет ресурсы без контроля | Документировать resource limits |
| T5 | Нет наблюдаемости | Не видно ошибок/состояния | Минимальные метрики событий и health probe |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
